# Club Infinity

## Descripción
Club Infinity es una plataforma web para
consultar servicios deportivos y recibir
solicitudes de contacto.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB Atlas

## Funcionalidades
- Página principal.
- Catálogo de servicios.
- Recomendador por palabras clave.
- Formulario de contacto.
- Almacenamiento de solicitudes en MongoDB.
- Panel administrativo.

## Ejecución del proyecto

1. Instalar dependencias con npm install.
2. Configurar la variable MONGODB_URI en .env.
3. Ejecutar node server.js.
4. Abrir http://localhost:3001.
