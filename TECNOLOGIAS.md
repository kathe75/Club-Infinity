# Tecnologías utilizadas en Club Infinity

## Frontend
- HTML5: estructura de las páginas.
- CSS3: diseño y adaptación a diferentes pantallas.
- JavaScript: interactividad y funcionalidades.

## Backend
- Node.js: entorno de ejecución.
- Express: gestión del servidor y las rutas.

## Base de datos
- MongoDB Atlas: almacenamiento de solicitudes de contacto.

## Herramientas de desarrollo
- Visual Studio Code: edición del código.
- Git: control de versiones.
- GitHub: almacenamiento del repositorio.
- Google Chrome: pruebas del sitio web.
