# Base de datos de Club Infinity

## Sistema utilizado
MongoDB Atlas.

## Base de datos
club_infinity

## Colección
solicitudes

## Campos de cada solicitud
- nombre: nombre del usuario.
- correo: correo electrónico.
- servicio: servicio deportivo seleccionado.
- mensaje: contenido de la solicitud.
- fecha: fecha de registro.

## Funcionamiento
El servidor recibe los datos del formulario
y los almacena en la colección solicitudes.
El panel administrativo permite consultar
los registros mediante la API.
